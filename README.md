# TanPit-01 · 南冈鞣场

鞣坑场地图作业台。登录后是按行列铺开的坑位，点坑登记浸液酸碱度并改状态。

## 技术栈

| 层 | 技术 |
| --- | --- |
| Web API | Django 5 · Django Ninja（不是 DRF 视图集） |
| 结构 | Django app `pits`：models / rules / api 分文件 |
| 数据 | Django ORM · PostgreSQL 15 |
| 前端 | Lit 3 Web Component · Vite |
| 部署 | Docker Compose |

- PostgreSQL：localhost:6170

## 业务规则

顶栏可在**坑位场地图**与**联签簿**两个独立页之间切换。

- 登记浸液酸碱度、把坑改成「鞣制中」均**不看联签**。
- 把坑标为「已放液」须同时满足：
  1. 最近一次浸液酸碱度在 **3.5～5.0**；
  2. 该坑的**现行联签簿**上有**两名不同人**的未撤回签字。
- 仅一人签字、或两人同名（按人去重）都不算满额，放液会被挡下。
- 规则在 `backend/pits/rules.py`。

### 联签簿

- 每坑至多一本**现行**（未撤回）联签簿；两名主管同时各交一本时，行锁串行 + 部分唯一索引 `uniq_active_book_per_pit` 兜底，只留一本，另立返回 `409`。
- 每本簿两个签格。签字记录签字人、签字时刻，可空的撤回时刻与撤回人。
- 操作工可为**本人**签字；同一坑未撤回签字按人去重（部分唯一索引 `uniq_active_signature_per_book_person`），满两人即封格。
- **撤回**（单条签字或整本簿）仅管理员可操作；整本撤回后簿上签字一并作废，可另立新簿。
- 联签簿专页可按坑筛选，双格签字、撤回均可在列表内完成。

## 种子

干净起步：一口「鞣制中」坑（`中-1`），最近酸碱度 `4.2` 已落在带内，**零签字**。用 `admin` / `worker` 两名不同人各签一次即可满足放液联签。
